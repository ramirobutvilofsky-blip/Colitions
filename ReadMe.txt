HOW IT WORKS:

In 'parameters.py' you can change the following variables:

g: gravity
If you want the particles to accelerate down, put negative values. 0 gravity is also an option.

e: elasticity
For full elasticity set 1. 
For partial elasticity set numers below 1 (for example 0.7)

n: cell definition
For optimization, the screen is divided into cells. More cell definition means more performance.
If you need more than 5000 particles, n = 100 will be enough. For less than 50 particles and
greater particle sradius, n between 1 an 10 is recommended.

In 'mass_creator.py' you can change everything about the  particles.

-number
-mass
-radius
-colors
-initial positions
-velocity and acceleartion

Choose whatever you most enjoy.
